# Cho Ren Sha 68k — installation

Requires Retro-Go SD **v2.0.0-rc1 or later** on the Game & Watch.

1. Copy the `homebrews` folder of the zip to the SD card's root:

       /homebrews/ChoRenSha.bin
       /homebrews/ChoRenSha.crs

   Both files side by side, with the same name. A `/homebrew/ChoRenSha`
   folder or files in `/homebrew/` from an earlier build can be deleted.

2. Start "Cho Ren Sha 68k" from the Homebrew tab. The first start copies
   the pack (about 10 MB) to the external flash ("Caching game"): the flash
   needs that much room.

Controls: D-pad = move, A = shot, B = bomb, GAME (START on Zelda units) =
pause, PAUSE/SET = Retro-Go menu: save states, Auto fire, Music,
Backgrounds (`1.10`: the new backgrounds of ver1.10, `1.0x`: the original
ones). High scores and settings: `/retro-go/saves/crs68k/`.

# Cho Ren Sha 68k — installation (français)

Nécessite Retro-Go SD **v2.0.0-rc1 ou plus récent** sur la Game & Watch.

1. Copier le dossier `homebrews` du zip à la racine de la carte SD :

       /homebrews/ChoRenSha.bin
       /homebrews/ChoRenSha.crs

   Les deux fichiers côte à côte, avec le même nom. Un dossier
   `/homebrew/ChoRenSha` ou des fichiers dans `/homebrew/` d'une version
   précédente peuvent être supprimés.

2. Lancer « Cho Ren Sha 68k » depuis l'onglet Homebrew. Au premier
   lancement, le pack (environ 10 Mo) est copié dans la flash externe
   (« Caching game ») : il faut cette place libre dans la flash.

Commandes : croix = déplacements, A = tir, B = bombe, GAME (START sur les
modèles Zelda) = pause, PAUSE/SET = menu Retro-Go : sauvegardes, Auto fire
(tir automatique), Music (musique), Backgrounds (`1.10` : les nouveaux
décors de la ver1.10, `1.0x` : ceux d'origine). Meilleurs scores et
réglages : `/retro-go/saves/crs68k/`.
